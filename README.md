🎶 ラジオプレイヤーウェブサイト 🎧
Radio Player Website へようこそ！このシンプルでユーザーフレンドリーなウェブアプリでは、世界中のインターネットラジオ局をストリーミングで聴くことができます。音楽、トークショー、アンビエントサウンドなど、あらゆるジャンルのラジオを楽しめます！

🔥 機能
🚀 ライブラジオ: ブラウザから直接、ライブラジオ局をストリーミング！
🎧 多彩なジャンル: 音楽ジャンルからトークショー、アンビエントまで、さまざまなラジオ局を楽しめます。
🎨 美しいインターフェース: 見やすく、使いやすいデザインで、どなたでも快適に利用できます。
🎯 カスタマイズ可能: 自分のお気に入りのラジオ局を簡単に選択できます。
🌍 グローバルアクセス: 世界中のラジオ局にアクセス可能です。
🖥️ デモ

📦 インストール方法
このプロジェクトを開始するには、以下の簡単な手順を実行してください。

1. リポジトリをクローン
ターミナルを開いて、以下のコマンドを実行します：

コードをコピーする
git clone https://github.com/your-username/radio-player-website.git

2. アプリを開く
ブラウザで http://localhost:3000 にアクセスして、ライブラジオを聴き始めましょう！

🛠️ 仕組み
このラジオプレイヤーアプリは、HTML5、CSS、JavaScript などの最新のウェブ技術を使って構築されています。主な機能は以下の通りです：

ラジオ局リスト: ラジオ局のURLをリストとして取得し、表示します。
ラジオボタン: クリックすることで異なるラジオ局に簡単に切り替えられます。
主なコンポーネント：
ラジオボタン: アプリではラジオ局のリストを表示し、それぞれのボタンが特定のラジオ局に対応しています。
💻 使用技術
HTML5: ページ内容を構造化するために使用。
CSS3: 美しいデザインを作成するために使用。
JavaScript: サイトにインタラクティブな機能を加えるために使用（ラジオプレイヤー機能など）。

📱 モバイルフレンドリー
ラジオプレイヤーは完全にレスポンシブデザインになっており、デスクトップとモバイルデバイスの両方で動作します。外出先でもお気に入りのラジオ局を楽しめます！

🎨 カスタマイズ方法
自分のラジオ局を追加するのは簡単です。以下の手順でカスタマイズできます。

新しいラジオ局を追加:
radio.js 内の stations 配列に新しいラジオ局のURLを追加するだけです。
各エントリには、表示用の name（名前）と src（URL）を指定できます。
例:

javascript
コードをコピーする
const ch_list = [
  { name: "ロックステーション", src: "http://rockstation.com/stream" },
  { name: "ジャズラジオ", src: "http://jazzradio.com/stream" }
];
見た目のカスタマイズ:
CSSファイルを変更して、レイアウト、色、フォントなどを自分好みに変更できます。
🐞 トラブルシューティング
問題が発生した場合、よくある問題とその解決方法を以下に示します：

音声が再生されない: ラジオ局のURLが正しくて動作していることを確認してください。URLを直接ブラウザで開いてテストできます。
